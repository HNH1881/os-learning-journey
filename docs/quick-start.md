# Quick Start

## 1. Open the vault

Open the repository root in Obsidian, or open `notes-en/` and `notes-zh/` as separate vaults.

## 2. Start with the index

- English: `notes-en/00-index.md`
- Chinese: `notes-zh/00-索引.md`

## 3. Follow the sequence

Study in order and then do the practical project work.

## 4. Use templates

Templates are stored in `shared/templates/`.
