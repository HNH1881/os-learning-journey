# 00. Index / 索引

## Overview / 总览

English:
The OS learning vault is organized by concept, from the fundamentals of computer architecture to the design of a small kernel.

中文:
这个操作系统学习仓库按主题组织，从计算机架构基础到一个小型内核的设计，逐步展开学习。

## Reading order / 阅读顺序

English:
The sequence is: computer principles, assembly, boot, memory, paging, processes, IPC, filesystem, I/O, and then lab work and the mini-kernel project.

中文:
学习顺序是：计算机原理、汇编、启动、内存、分页、进程、IPC、文件系统、I/O，然后进入实验和 mini-kernel 项目。

## Main themes / 主题概览

English:
- CPU and registers
- memory hierarchy
- boot and protected mode
- paging and virtual memory
- processes and threads
- IPC and filesystems
- drivers and interrupts
- kernel construction

中文:
- CPU 与寄存器
- 存储层次结构
- 启动与保护模式
- 分页与虚拟内存
- 进程与线程
- IPC 与文件系统
- 驱动与中断
- 内核构建

## Working principle / 学习原则

English:
The key is to connect hardware, machine instructions, OS abstractions, and practical experiments into one coherent mental model.

中文:
关键在于把硬件、机器指令、操作系统抽象和实际实验连接成一个完整的认知模型。
