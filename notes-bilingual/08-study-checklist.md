# 08. Study Checklist / 学习清单

## Foundation / 基础

English:
- binary and hexadecimal
- Boolean logic
- CPU and registers
- memory hierarchy
- stack and heap

中文:
- 二进制和十六进制
- 布尔逻辑
- CPU 和寄存器
- 存储层次结构
- 栈和堆

## Boot and machine execution / 启动与底层执行

English:
- real mode
- protected mode
- long mode
- GDT
- boot sector

中文:
- 实模式
- 保护模式
- 长模式
- GDT
- 启动扇区

## Memory and paging / 内存与分页

English:
- virtual memory
- page tables
- CR3
- page faults
- paging basics

中文:
- 虚拟内存
- 页表
- CR3
- 缺页异常
- 分页基础

## Processes and threads / 进程与线程

English:
- process lifecycle
- thread vs process
- context switch
- scheduler
- race conditions

中文:
- 进程生命周期
- 线程与进程的区别
- 上下文切换
- 调度器
- 竞态条件

## OS abstractions / 抽象机制

English:
- system calls
- IPC
- filesystem and inode
- device drivers
- interrupts and DMA

中文:
- 系统调用
- IPC
- 文件系统与 inode
- 设备驱动
- 中断与 DMA

## Final goal / 最终目标

English:
You should be able to explain boot flow, virtual memory, scheduling, and how the OS manages hardware safely.

中文:
你应该能够解释计算机如何启动、内存如何虚拟化、任务如何调度，以及操作系统如何安全管理硬件资源。
