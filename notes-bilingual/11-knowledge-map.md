# 11. Knowledge Map / 知识地图

## Core map / 核心地图

English:
Program -> Assembly -> CPU -> Memory -> Paging -> Processes -> Threads -> IPC -> Filesystem -> Devices -> Kernel

中文:
程序 -> 汇编 -> CPU -> 内存 -> 分页 -> 进程 -> 线程 -> IPC -> 文件系统 -> 设备 -> 内核

## Relationship / 关系

English:
Boot code prepares the environment; paging provides isolation; system calls bridge user mode and kernel mode; device drivers connect software to hardware.

中文:
启动代码准备环境；分页提供隔离；系统调用连接用户态与内核态；设备驱动连接软件与硬件。

## Study concept / 学习概念

English:
Do not isolate concepts. Always connect a topic to its lower-level mechanism and higher-level purpose.

中文:
不要孤立地记忆概念，要始终把一个主题与更底层的机制和更高层的目的连接起来。
