# 13. Experiment Progress Log / 实验进度日志

## Template / 模板

English:
- date
- objective
- steps
- code
- output
- observations
- what I learned
- problems and fixes
- next step

中文:
- 日期
- 目标
- 步骤
- 代码
- 输出
- 观察
- 学到的内容
- 问题与修正
- 下一步

## Reflection rule / 反思原则

English:
Keep a log after every lab so you can identify weak concepts and track your actual understanding over time.

中文:
每次实验后都要记录日志，这样可以找到薄弱概念，并追踪自己的真实理解进展。
