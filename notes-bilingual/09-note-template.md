# 09. Note Template / 笔记模板

## Structure / 结构

English:
- Topic
- Summary
- Key ideas
- Why it matters
- Definitions
- Mechanism
- Example
- Pitfalls
- Review questions

中文:
- 主题
- 概要
- 关键点
- 为什么重要
- 定义
- 机制
- 示例
- 常见坑
- 复习问题

## Example block / 示例块

English:
```markdown
## Topic
- Title:
- Date:
- Related notes:

## Summary
...
```

中文:
```markdown
## 主题
- 标题：
- 日期：
- 相关笔记：

## 概要
...
```

## Review rule / 复习规则

English:
Use the template to convert weak concepts into plain-language explanations with examples and follow-up questions.

中文:
用这个模板把模糊概念改写成用自己的语言解释，并附上例子和追问问题。
