# OS Learning Vault

This repository contains a structured operating-system learning vault designed for Obsidian.

## Directory overview

- `notes-en/` — English-language learning notes
- `notes-zh/` — 中文学习笔记
- `projects/` — hands-on practice projects
- `shared/` — shared resources and templates
- `docs/` — setup and quick-start documentation

## Recommended Obsidian usage

Open the vault by selecting the repository root or one of these folders:

- `notes-en/` for English learning notes
- `notes-zh/` for Chinese learning notes

## Core project

- `projects/mini-kernel/` — minimal kernel prototype built with QEMU, NASM, GCC

## Quick start

1. Open `notes-en/README.md` or `notes-zh/README.md`
2. Follow the learning order in the index file
3. Use the project folder for hands-on practice
4. Record experiments in your own notes using the templates in `shared/templates/`

## Learning flow

- Basics and theory
- Assembly and boot process
- Memory and paging
- Processes and threads
- Filesystem and IPC
- I/O and drivers
- Mini-kernel practice
