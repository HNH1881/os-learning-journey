# 05. 进程与线程

## 1. 程序和进程的区别

程序是磁盘上的静态代码。
进程是一个正在运行的程序实例。

进程包含：
- 代码
- 数据
- 堆
- 栈
- 页表
- 进程 ID
- 执行状态

## 2. 进程创建

操作系统创建进程时通常会：
- 分配新的进程结构
- 建立页表
- 加载程序镜像
- 初始化寄存器
- 将其放入就绪队列

## 3. 进程状态

常见状态：
- new：新建
- ready：就绪
- running：运行中
- waiting / blocked：等待中
- terminated：已结束

## 4. 线程

线程是进程内部的执行单元。
线程共享：
- 进程地址空间
- 堆
- 全局变量

线程有：
- 自己的栈
- 自己的寄存器
- 自己的执行上下文

## 5. 进程和线程的区别

### 进程
- 独立虚拟地址空间
- 创建/切换成本更高
- 隔离更强

### 线程
- 共享地址空间
- 切换成本更低
- 更适合并发执行

## 6. 上下文切换（Context Switch）

上下文切换指：
- 保存当前线程/进程的状态
- 恢复下一个线程/进程的状态
- 切换 CPU 到新任务

## 7. 调度器

调度器决定哪个可运行任务下一步获得 CPU。
常见目标：
- 公平性
- 吞吐量
- 响应时间
- 易用性

## 8. 常见调度算法

- Round Robin 轮询
- FCFS 先来先服务
- SJF 最短作业优先
- Priority scheduling 优先级调度
- multilevel feedback queue 多级反馈队列

## 9. 时间片

时间片是调度器给每个任务分配的一段执行时间。

太短会导致：
- 上下文切换过多

太长会导致：
- 系统响应变差

## 10. 为什么线程很常见

线程允许一个进程中同时进行多个任务。
常见用途：
- Web 服务器
- 图形界面
- 后台处理
- 数据处理

## 11. 为什么线程也危险

线程共享内存，因此容易出现：
- 竞争条件
- 死锁
- 饥饿
- 数据不一致

## 核心思想

进程提供隔离，线程提供并发。调度器负责在有限的 CPU 资源上决定谁��什么时候执行。

## 一句话总结

操作系统通过进程和线程模型把“并发执行”变成可管理的抽象，并靠调度器协调 CPU 使用。
