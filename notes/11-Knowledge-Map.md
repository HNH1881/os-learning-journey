```text
程序 -> 汇编 -> CPU -> 内存 -> 页表 -> 进程
    -> 系统调用 -> 内核 -> 设备驱动 -> 硬件
    -> ��件 API -> 文件系统 -> 存储
    -> IPC -> 其他进程
```

## 9. 关键关系

- 启动代码为操作系统运行创造环境。
- 分页实现进程隔离和内存保护。
- 系统调用连接用户程序和内核服务。
- 进程和线程决定任务如何调度。
- IPC 和文件系统让进程共享通信和持久数据。
- 设备驱动和中断把软件连接到真实硬件。

## 10. 长期学习原则

不要孤立记忆概念，要始终把每个概念和更底层机制、以及更高层目的关联起来。
