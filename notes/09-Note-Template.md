## 示例填充

### 主题
CPU 寄存器

### 概念总结
寄存器是 CPU 内部的高速存储区域，用于当前指令的计算和数据处理。

### 核心思想
寄存器保存 CPU 当前的工作状态。

### 为什么重要
没有寄存器，CPU 就无法高效运算和处理临时数据。

### 关键定义
- 寄存器
- 指令指针
- 栈指针

### 工作机制
CPU 从内存取指令，加载寄存器中的操作数，执行指令，再把结果��回寄存器或内存。

### 示例
```asm
mov rax, 10
mov rbx, 20
add rax, rbx
```

### 常见坑
- 把寄存器和内存混淆
- 忘了寄存器数量有限
- 认为高层变量直接对应一个寄存器

### 复习问题
- 寄存器和内存有什么区别？
- 为什么函数调用要用栈？
- 为什么 CPU 需要寄存器？
