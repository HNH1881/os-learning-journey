# 15. mini-kernel 项目计划

这是从理论知识走向实践的核心路线，目标是：在 QEMU 中启动一个最小的 x86_64 内核，并输出文字。

## 项目目标

最终目标是建立一个最小内核，能够：
- 从启动扇区启动
- 进入长模式
- 设置分页
- 输出文本
- 调用 C 代码
- 后续扩展中断、内存管理和调度

## 最终里程碑

得到如下输出：

```text
Hello from mini kernel!
```

然后循环等待。

## 里程碑 1：启动扇区

### 目标
在实模式中输出一句文字。

### 任务
- 创建 512 字节的 boot sector
- 使用 BIOS 中断输出字符
- 在 QEMU 中验证执行

### 关键知识
- 实模式
- boot sector
- `0x7C00`
- `0xAA55`

---

## 里程碑 2：进入长模式

### 目标
从实模式进入长模式。

### 关键任务
- 定义 GDT
- 进入保护模式
- 开启 PAE
- 打开 EFER 的 LME 位
- 跳转到 64 位代码

### 学到的内容
- CPU 模式切换
- GDT
- 保护模式
- 长模式

---

## 里程碑 3：启用分页

### 目标
建立页表并开启分页。

### 关键任务
- 配置 PML4 / PDPT / PD
- 设置 CR3
- 启用分页
- 做恒等映射

### 学到的内容
- 虚拟内存
- 页表
- page fault
- 地址翻译

---

## 里程碑 4：VGA 文本输出

### 目标
让内核直接输出字符到屏幕。

### 关键任务
- 访问 VGA 文本缓冲区
- 实现 `putchar` / `print_string`
- 输出文本而不是只靠 BIOS 中断

### 学到的内容
- 直接硬件访问
- 内核输出机制
- 文本模式

---

## 里程碑 5：C 内核入口

### 目标
把汇编启动逻辑连接到 C 内核函数。

### 关键任务
- 创建 `kernel_main()`
- 从汇编跳到 C
- 从 C 输出到屏幕

### 学到的内容
- C / 汇编链接
- 内核入口点
- 结构化代码组织

---

## 里程碑 6：中断与键盘输入

### 目标
理解异步事件处理机制。

### 关键任务
- 安装 IDT
- 编写中断处理器
- 对键盘或定时器做处理

### 学到的内容
- 中断
- IDT
- 设备事件驱动

---

## 里程碑 7：内存管理器

### 目标
维护页框或堆管理。

### 关键任务
- 跟踪空闲页
- 简单 allocator
- 输出内存状态

### 学到的内容
- 物理内存管理
- 分页和页框
- 资源所有权

---

## 里程碑 8：调度器骨架

### 目标
让多个任务具有“执行上下文”和“切换”概念。

### 关键任务
- 定义 task 结构
- 为任务保存寄存器状态
- 创建最简单的 round robin

### 学到的内容
- 任务调度
- 上下文切换
- 进程/线程模型

---

## 里程碑 9：用户态准备

### 目标
为未来的用户态程序执行做好准备。

### 关键任务
- 识别 Ring 3 / Ring 0
- 设计用户栈
- 为系统调用做准备

### 学到的内容
- 用户态和内核态
- 特权机制
- 系统调用边界

---

## 推荐推进顺序

1. boot sector：能输出文本
2. long mode：能进入 64 位
3. paging：能开启分页
4. VGA：能向屏幕输出文本
5. C kernel：能从 C 代码运行
6. interrupts：处理设备事件
7. memory manager：管理内存
8. scheduler：管理任务
9. userspace：准备用户模式程序

---

## QEMU 常用命令

```bash
qemu-system-x86_64 -drive format=raw,file=build/boot.bin
```

或者直接在项目目录：

```bash
make run
```

## 最后一句话

这个项目不是为了“做出一个完整 OS”，而是让你从最底层的启动和 CPU 模式，逐步走向真实的内核设计思维。
