# 12. QEMU + NASM + GCC 实验清单

## 1. Setup / 环境准备

Install QEMU, NASM, GCC, GDB, and binutils.

安装 QEMU、NASM、GCC、GDB 和 binutils。

## 2. Lab 1 / 实验 1

Write a minimal hello-world assembly program.

编写最小的汇编 Hello World 程序。

## 3. Lab 2 / 实验 2

Compile a C program and inspect the generated assembly.

编译 C 程序并检查生成的汇编代码。

## 4. Lab 3 / 实验 3

Run a boot sector in QEMU.

在 QEMU 中运行启动扇区。

## 5. Summary / 总结

These labs connect theory with real execution.

这些实验把理论和真实执行连接起来。
