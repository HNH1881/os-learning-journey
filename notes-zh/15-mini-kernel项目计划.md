# 15. mini-kernel 项目计划

## Goal / 目标

Build the smallest possible kernel that can boot and print output in QEMU.

构建最小可运行内核，使其能在 QEMU 中启动并输出字符。

## Milestones / 里程碑

1. Boot sector / 启动扇区
2. Long mode / 长模式
3. Paging / 分页
4. VGA output / VGA 输出
5. C kernel entry / C 内核入口
6. Interrupts / 中断
7. Memory manager / 内存管理器
8. Scheduler / 调度器

## Summary / 总结

A mini-kernel is the most practical way to turn theory into real operating-system understanding.

mini-kernel 是把理论变成真实操作系统理解的最实用途径。
