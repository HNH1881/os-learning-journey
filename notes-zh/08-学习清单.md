# 08. 学习清单

## Foundation / 基础

- Binary and hex / 二进制和十六进制
- Boolean logic / 布尔逻辑
- CPU and registers / CPU 与寄存器
- Memory hierarchy / 内存层次结构

## Low-level / 底层

- Assembly basics / 汇编基础
- Stack and function calls / 栈与函数调用
- System calls / 系统调用
- Boot and mode transitions / 启动与模式切换

## Advanced / 进阶

- Paging and page faults / 分页和缺页异常
- Processes / 进程
- Threads / 线程
- IPC and filesystem / IPC 和文件系统
- Device drivers / 设备驱动

## Practice / 实践

- Run a boot sector in QEMU / 在 QEMU 中运行启动扇区
- Compile C into assembly / 编译 C 到汇编
- Understand a page table / 理解页表
- Run a process and thread example / 运行进程和线程示例

## Summary / 总结

This checklist connects concepts to practice.

这份清单把概念与实践连接起来。
