# 05. 进程与线程

## 1. Program vs process

A program is static code stored on disk. A process is that code loaded and running in memory.

程序是存放在磁盘上的静态代码；进程是已加载并正在内存中运行的程序实例。

## 2. Process states

Processes typically have states such as new, ready, running, waiting, and terminated.

进程典型状态包括 new、ready、running、waiting 和 terminated。

The scheduler moves them among states based on execution and resource availability.

调度器根据执行状态和资源可用性在这些状态之间移动进程。

## 3. Threads

A thread is a lightweight execution unit inside a process.

线程是进程内的轻量执行单元。

Threads share the same memory space but have separate stacks and registers.

线程共享同一内存空间，但拥有独立的栈和寄存器。

## 4. Context switch

A context switch saves the current task state and restores another task's state.

上下文切换会保存当前任务状态，并恢复另一个任务的状态。

This is how the OS runs many tasks on a single CPU.

这也是操作系统如何让单个 CPU 运行多个任务的方式。

## 5. Scheduler

The scheduler chooses which task runs next.

调度器决定下一个运行哪个任务。

Important goals include fairness, latency, and throughput.

关键目标包括公平性、响应延迟和吞吐量。

## 6. Summary / 总结

Processes provide isolation. Threads provide concurrency. The scheduler coordinates them all.

进程提供隔离，线程提供并发，调度器协调它们的运行。
