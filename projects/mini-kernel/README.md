# Mini Kernel Project

This folder stores the practical project used for hands-on operating-system learning.

## Contents

- `src/` — source files
- `build/` — generated binaries
- `Makefile` — build script
- `README.md` — project overview

## Quick start

```bash
cd projects/mini-kernel
make run
```

## Phase goals

1. Boot sector output
2. Long mode entry
3. Paging
4. VGA output
5. Kernel C entry
