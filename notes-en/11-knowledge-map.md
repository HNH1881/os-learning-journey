# 11. Knowledge Map

## Foundation / 基础

Binary, CPU, registers, and memory form the hardware foundation.

二进制、CPU、寄存器和内存形成硬件基础。

## Boot / 启动

The boot sequence turns hardware into an executable OS environment.

启动流程把硬件转化成可执行的操作系统环境。

## Memory / 内存

Paging creates abstraction and isolation.

分页创造抽象和隔离。

## Processes / 进程

Processes and threads handle execution and scheduling.

进程和线程处理执行与调度。

## Summary / 总结

All layers connect into one operating-system model.

所有层次最终连接成一个操作系统模型。
