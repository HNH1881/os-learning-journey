# 13. Experiment Progress Log

## Goal / 目标

Record each experiment, output, and learning result.

记录每一次实验、输出和学习成果。

## Template / 模板

- Date / 日期
- Tools / 工具
- Steps / 步骤
- Output / 输出
- Learning / 收获
- Problems / 问题
- Next step / 下一步

## Summary / 总结

The log turns experimentation into evidence and reflection.

实验日志把实践转化为证据和反思。
